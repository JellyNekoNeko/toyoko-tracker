# Phase 6 데이터, 백업 및 진단

WebUI 또는 데스크톱 앱에서 **화면 설정 → 데이터 및 백업**을 엽니다.

## 내보내기와 가져오기

**백업 내보내기**는 형식 버전, 파일 크기와 SHA-256을 기록한 ZIP을 만듭니다.
기본 대상은 설정, 모니터 작업, 가격 알림, 여행 목록과 유연 날짜 작업입니다.
기록 옵션을 켜면 가격, 알림, 이벤트와 작업 실행 기록도 포함합니다. 공유 가능한
백업에서는 푸시 및 이메일 인증정보를 제거합니다.

가져오기 전에 **가져오기 미리보기**를 실행해야 합니다. 경로와 크기, 매니페스트,
모든 SHA-256, SQLite 무결성과 기본 키 충돌을 검사한 뒤 적용 버튼을 활성화합니다.
충돌 전략은 기존 항목 유지, 백업으로 덮어쓰기, 백업에 포함된 데이터 교체입니다.

적용 전에 전체 롤백 ZIP을 자동 생성합니다. 데이터베이스는 임시 복사본에서
병합하고 무결성과 외래 키를 검사한 뒤 원자적으로 교체합니다. 실행 중인 유연 날짜
검색은 먼저 일시 중지해야 합니다.

## 업데이트 백업, 정리와 진단

데스크톱 업데이트는 SHA-256과 서명자 일치를 확인한 뒤 앱 교체 전에 전체 백업을
만들고 `rollback.json`에 버전, 자산 이름, 앱 및 데이터 복구 정보를 기록합니다.

저장소 화면에는 저장 위치, DB 크기, Schema와 테이블 행 수가 표시됩니다. 정리는
선택한 캐시 또는 기록만 삭제하며 핵심 작업, 규칙, 여행 목록, 설정과 최신 백업을
유지합니다.

진단 보고서와 지원 번들은 DB, 쓰기 권한, OS/CPU, Python, 의존성과 실행 상태를
검사합니다. 인증정보는 자동으로 제거되며 지원 번들에는 별도 매니페스트와
SHA-256이 포함됩니다.
