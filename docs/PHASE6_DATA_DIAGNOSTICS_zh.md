# Phase 6 数据、备份与诊断

在 WebUI 或桌面版中打开 **界面设定 → 数据与备份**。

## 导出与导入

点击 **导出备份** 会生成带版本清单、文件大小和 SHA-256 的 ZIP。默认包含
设置、监控任务、价格提醒、旅行清单和灵活日期任务；勾选历史选项后还会加入
价格、提醒、事件和任务运行历史。可分享备份会移除推送及邮件凭据。

导入必须先点击 **预览导入**。程序会检查路径、大小、清单版本、每个文件的
SHA-256、SQLite 完整性和主键冲突，然后才启用确认按钮。三种冲突策略分别是
保留现有项、使用备份覆盖，以及替换备份实际包含的数据组。

正式导入前会自动生成完整回滚包；数据库在临时副本中合并并通过完整性与外键
检查后再原子替换。导入期间监控服务会暂停，完成后自动重新加载。正在运行的
灵活日期检索需要先暂停。

## 升级备份、清理与诊断

PyPI/pipx 更新会在调用包管理器前生成完整备份；桌面更新包通过 SHA-256 和签名
身份检查后、替换应用前也会执行相同备份，并把版本、安装方式或资源名、应用
回滚位置和数据备份摘要写入 `rollback.json`。

存储卡显示配置目录、数据库位置、占用空间、Schema 版本和数据表统计。清理
仅作用于选中的缓存或历史类别，核心任务、规则、清单、设置及最新备份会保留。

诊断中心检查数据库、写入权限、Python/系统架构、依赖和运行状态。复制报告与
支持包都会脱敏；支持包还会执行凭据扫描，并带独立清单及 SHA-256。
